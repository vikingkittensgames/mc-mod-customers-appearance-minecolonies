# MineColonies Appearance Configuration

Configure the add-on through NeoForge's mod configuration screen or
`config/customers_minecolonies_appearance-common.toml`.

| Setting | Default | Effect |
| --- | ---: | --- |
| Maximum nearby-colony distance | 128 | Maximum distance from the spawner to a fallback colony center. |
| Enable Noble Customers | true | Adds nobles to the Customer pool. |
| Enable Aristocrat Customers | true | Adds aristocrats to the Customer pool. |
| Enable job-specific Customers | false | Adds MineColonies profession models to Customers. |
| Enable production-role Suppliers | false | Adds production professions to Suppliers. |
| Enable guard models | false | Allows archer and knight models. |
| Enable child and student models | false | Allows young models. |

When child or student models are enabled, their smaller models are adjusted
while sitting so they align with the seat and their wanted-item display stays
near their head.
